# JMA Tipovačka

## O projektu

JMA Tipovačka je univerzální webová aplikace pro pořádání sportovních tipovacích soutěží.

Projekt vznikl původně pro Mistrovství světa ve fotbale 2026, ale od začátku je navržen jako obecný systém, který umožní vytvářet libovolné sportovní soutěže.

Například:

- Mistrovství světa
- Mistrovství Evropy
- Extraliga
- Liga mistrů
- NBA
- Euroliga
- Firemní tipovačky
- Soukromé soutěže

Každá soutěž může mít vlastní:

- název
- logo
- banner
- pravidla
- bodování
- datum konání
- výši startovného

---

## Cíle projektu

Hlavní cíle aplikace:

- jednoduché ovládání pro hráče
- rychlá administrace soutěží
- univerzální použití pro různé sporty
- responzivní zobrazení pro mobil i počítač
- snadná rozšiřitelnost o nové funkce

---
